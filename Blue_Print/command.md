Tugas berikutnya hanya merapikan dokumentasi kerja.

1. Cari dokumen status server dan SOP yang sudah ada.
   Gunakan dokumen tersebut agar tidak membuat panduan ganda.

2. Simpan konteks server yang sudah dibaca pada checkout
   pengembangan, bukan direktori rilis aktif di VPS.

3. Tambahkan rujukan pada petunjuk proyek yang dibaca AI,
   agar setiap sesi baru mengetahui lokasi dokumentasi ini.
   Pertahankan instruksi proyek yang sudah ada.

4. Catat alur:
   pengembangan → pengujian → GitHub → CI berhasil
   → deployment saat diminta pemilik → verifikasi → catat versi.

5. Bedakan prosedur yang sudah terbukti bekerja dengan
   rencana otomasi yang belum dibuat atau belum tervalidasi.

Jangan mengubah aplikasi, database, konfigurasi server,
atau menjalankan deployment. Jangan push dahulu.

Laporkan lokasi dokumen dan ringkasan perubahannya.
